# MyChat 项目需求文档

## 项目概述

### 简介
MyChat 是一个前后端分离的即时通讯项目，具备后台管理、单聊群聊、联系人管理、多种消息（文本/文件/视频）处理、离线消息处理以及音视频通话等功能，旨在打造类似微信的聊天体验。

### 技术栈

#### 前端技术
- **Vue3** - 现代化的前端框架
- **Vue Router** - 前端路由管理
- **Vuex** - 状态管理
- **WebSocket** - 实时通信
- **Element UI** - UI组件库

#### 后端技术
- **Go** - 高性能后端语言
- **Gin** - Web框架
- **GORM** - ORM框架
- **GoRedis** - Redis客户端
- **WebSocket** - 实时通信
- **Kafka** - 消息队列
- **WebRTC** - 音视频通话
- **Zap** - 日志库

## 功能特性

### 1. 即时通讯功能

#### 1.1 单聊与群聊
- 支持一对一私聊和群聊
- 实时消息推送
- 群组创建、管理、解散
- 群成员权限管理

#### 1.2 联系人管理
- 添加、删除、拉黑联系人
- 好友申请处理
- 联系人分组管理
- 在线状态显示

#### 1.3 消息类型
- 文本消息
- 文件消息（支持多种格式）
- 音频消息
- 视频消息
- 表情包支持

#### 1.4 离线消息处理
- 确保用户离线时消息不丢失
- 上线后正常接收离线消息
- 消息状态同步

### 2. 音视频通话
- 基于WebRTC的1对1音视频通话
- 发起、拒绝、接听、挂断功能
- 通话质量优化
- 网络自适应调节

### 3. 后台管理
- 后台管理界面
- "靓号"用户权限控制
- 人员管理维护操作
- 系统监控和统计

### 4. 安全与验证
- 登录注册使用短信验证
- 支持SSL加密
- 确保用户信息安全
- **注意：** 当前可能不支持个人认证，可利用ChatGPT生成数据到user_info表中进行直接登录操作
- **待办：** 更改代码为QQ邮箱验证码登录

### 5. 数据存储
- 后台MySQL数据库
- 使用GORM进行数据库操作
- 确保数据持久化存储
- 数据备份和恢复

### 6. 日志记录
- 使用Zap日志库
- 记录系统操作日志
- 便于问题排查和性能监控
- 日志分级管理

### 7. 消息队列
- 使用Kafka处理消息队列
- 确保高效的消息传输和处理
- 消息持久化
- 负载均衡

### 8. 缓存系统
- 使用GoRedis进行缓存操作
- 提高系统性能
- 会话信息缓存
- 用户状态缓存

### 9. 实时通信
- 使用WebSocket实现实时消息推送
- 确保消息及时性
- 连接状态管理
- 断线重连机制

## 系统架构

### 前端架构
```
Vue3 + Vue Router + Vuex
    ↓
Element UI组件库
    ↓
WebSocket客户端
    ↓
WebRTC音视频
```

### 后端架构
```
Gin Web框架
    ↓
GORM + MySQL
    ↓
GoRedis + Kafka
    ↓
WebSocket + WebRTC
```

## 性能要求

- 消息延迟 < 100ms
- 支持并发用户数 > 1000
- 系统可用性 > 99.9%
- 音视频通话延迟 < 200ms

## 安全要求

- 数据传输加密（SSL/TLS）
- 用户身份验证
- 消息内容安全过滤
- 防SQL注入和XSS攻击
- 用户隐私保护

## 部署要求

- 支持Docker容器化部署
- 支持负载均衡
- 支持水平扩展
- 支持多环境部署（开发、测试、生产）

- 性能优化

## 风险评估

1. **技术风险**：WebRTC技术复杂度高，可能存在兼容性问题
2. **性能风险**：高并发场景下可能存在性能瓶颈
3. **安全风险**：即时通讯系统面临多种安全威胁
4. **合规风险**：需要符合相关法律法规要求

- 性能指标达到要求
- 安全测试通过
